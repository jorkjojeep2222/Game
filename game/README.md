# Barbarian Idle

เกม idle แนวเอาชีวิตรอด ตัวละครเดี่ยว ได้แรงบันดาลใจจากมังฮวา *Surviving the Game as a Barbarian*

---

## เริ่มต้นใช้งาน

```bash
npm install
npm run dev        # เปิดเล่นที่ http://localhost:5173
npm run bundle     # รวมเป็นไฟล์เดียวที่ dist/barbarian_idle.jsx (สำหรับเล่นใน artifact)
```

---

## โครงสร้างโฟลเดอร์

```
src/
├── core/          ตรรกะเกม ไม่มี UI เลย
│   ├── config.js      ★ ตัวเลขปรับสมดุลทั้งหมด — แก้ที่นี่ที่เดียว
│   ├── util.js        ฟังก์ชันช่วยเหลือ (fmt, clamp, expNeed …)
│   ├── character.js   สร้างสายเลือดและตัวละครใหม่
│   ├── derive.js      ★ คำนวณค่าทุกอย่างจาก state (pure function)
│   ├── simulate.js    ★ เดินเวลา 1 step — ใช้ทั้งเล่นสดและ offline
│   └── storage.js     อ่าน/เขียนเซฟ + ซ่อมเซฟเก่า
│
├── data/          ข้อมูลล้วน ไม่มีตรรกะ — เพิ่มเนื้อหาที่นี่
│   ├── world.js       ภัยสิ่งแวดล้อม / ฤดูกาล / ถิ่นล่าสัตว์ / เส้นทาง
│   ├── races.js       เผ่าพันธุ์ 5 เผ่า × คลาสละ 3
│   ├── traits.js      ลักษณะสายเลือด + รูน
│   ├── species.js     มอนสเตอร์ + สกิลเอสเซนส์
│   ├── items.js       ไอเท็ม / ความหายาก / วัตถุดิบ / กระเป๋า / สัตว์เลี้ยง
│   └── progression.js เควสต์ + ฉายา
│
├── art/
│   ├── sprites.js     ★ งานพิกเซลทั้งหมด (อาร์เรย์ของสตริง)
│   └── PixelScene.jsx วาดฉากต่อสู้ลง canvas
│
├── ui/
│   ├── theme.jsx      สไตล์กลาง + กฎกันหน้าจอกระตุก
│   └── widgets.jsx    Bar / Row / ItemCard / Modal / Popup
│
├── screens/
│   ├── CharacterCreate.jsx
│   ├── HuntScreen.jsx     หน้าจอหลัก
│   ├── Popups.jsx         กล่องข้อความกลางจอ
│   └── modals/            หน้าต่างซ้อน 5 หน้า
│
└── App.jsx        ตัวประสานงาน: ลูปเกม + actions + เลือกหน้าต่าง
```

**ทิศทางการพึ่งพา:** `data → core → ui/art → screens → App`
ห้ามให้ `core/` หรือ `data/` import อะไรจาก `screens/` หรือ `ui/` เด็ดขาด

## กฎสำคัญ 3 ข้อ

### 1. มี `simulate()` ตัวเดียว
ใช้ทั้งตอนเล่นสด (`dt ≈ 0.2` วิ) และตอนคำนวณ offline (`dt = 30` วิ)
ถ้าเขียนสูตรแยกสองชุด ตัวเลขสองโหมดจะเริ่มไม่ตรงกันภายในไม่กี่วัน

### 2. `derive()` ต้องเป็น pure function
รับ `state` กับ `now` คืนตัวเลข ห้ามแก้ state ห้ามสุ่ม
เพราะมันถูกเรียกทั้งตอนวาด UI และตอนจำลอง — ถ้ามันมีผลข้างเคียง เกมจะเพี้ยน

### 3. ค่าสมดุลอยู่ใน `config.js` เท่านั้น
อย่าฝังตัวเลขมหัศจรรย์ไว้กลางโค้ด

## วิธีเพิ่มเนื้อหา

### เพิ่มมอนสเตอร์
`src/data/species.js` → เพิ่ม entry ใน `SPECIES[ภัยสิ่งแวดล้อม]`

```js
{ id: 'iceworm', name: 'หนอนน้ำแข็ง', icon: '🪱',
  shape: 'serpent',                 // ชื่อทรงร่างใน art/sprites.js
  skill: 'frostbite',               // คีย์ใน SKILL_LIB
  pal: { o:'#0D2233', 1:'#6FB6DE', 2:'#C8ECFB', 3:'#2E5F86', e:'#FFE9A8' } }
```
ไม่ต้องแก้โค้ดวาดเลย

### เพิ่มสไปรต์ใหม่
`src/art/sprites.js` → เพิ่มใน `SHAPES`

```js
newShape: spr([
  '..oooo..',
  '.o1111o.',
  '.o1e1e1o',
]),
```
- 1 ตัวอักษร = 1 พิกเซล, `.` = โปร่งใส
- `spr()` เติมความยาวแถวให้เท่ากันอัตโนมัติ นับช่องพลาดก็ไม่พัง
- ตัวอักษรมาตรฐาน: `o` เส้นขอบ, `1` สีฐาน, `2` สีสว่าง, `3` สีเงา, `e` ตา, `t` เขี้ยว

### เพิ่มไอเท็ม
`src/data/items.js` → `BASES` (ฐาน) หรือ `AFFIXES` (คุณสมบัติสุ่ม)

### เพิ่มเควสต์
`src/data/progression.js` → `QUESTS` เรียงตามลำดับที่จะให้ผู้เล่นทำ
ใส่ `unlock: 'ชื่อคีย์'` เพื่อเปิดปุ่ม/แท็บใหม่

## บันทึกการแก้บั๊ก (v7)

| อาการ | สาเหตุ | วิธีแก้ |
|---|---|---|
| หน้าต่างเด้งขึ้นลงตลอด | โมดัลจัดกลางแนวตั้ง + ราคาสินค้าอัปเดตทุก 0.2 วิ ทำให้ข้อความในปุ่มยาวไม่เท่ากันแล้วตัดบรรทัด → ความสูงเปลี่ยน → ตำแหน่งขยับ | โมดัลใช้ `top/bottom` ตายตัว ความสูงคงที่ เนื้อหาเลื่อนข้างใน |
| ตัวเลขดันข้อความข้างๆ | ตัวเลขเปลี่ยนหลักแล้วความกว้างเปลี่ยน | คลาส `.fixw` + `minWidth` เป็นหน่วย `ch` |
| ปุ่มตัดบรรทัดแล้วความสูงกระโดด | ข้อความยาวเกิน | `.nowrap` บนปุ่มทุกอันที่มีตัวเลข |
| เนื้อหาเลื่อนซ้ายขวา | แถบเลื่อนโผล่/หายตามความสูงหน้า | `html{overflow-y:scroll}` |
| แถบเควสต์/ปุ่มทักษะโผล่แล้วดันของข้างล่าง | เรนเดอร์แบบมี/ไม่มี | จองความสูงด้วย `minHeight` |
| มอนสเตอร์ไม่โผล่เลย | ต้องผ่านเควสต์ที่ 5 ก่อนถึงจะ spawn | ลดเหลือผ่านเควสต์แรก + ตัวแรกโผล่ใน 18 วิ + แสดงนับถอยหลังบนจอ |
| เลเวลขึ้นช้าผิดปกติตอน offline | ลูปเลเวลอัปมี `break` ขึ้นได้แค่ 1 เลเวลต่อ step | วนได้สูงสุด 50 เลเวลต่อ step |

- งานศิลป์ยังเป็นระดับ placeholder (6 ทรงร่าง ใช้ร่วมกัน 14 สายพันธุ์ด้วยการเปลี่ยนจานสี)
- ยังไม่มีอนิเมชันหลายเฟรม (ตอนนี้ใช้การขยับตำแหน่งกับหมุนอาวุธแทน)
- ยังไม่มีเสียง
- ยังไม่ได้จูนสมดุลช่วงเลเวล 15–30
