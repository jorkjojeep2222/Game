# สเปกไฟล์ภาพสไปรต์ชีต

วางไฟล์ `.png` ไว้ในโฟลเดอร์นี้ (`public/assets/sprites/`) แล้วเกมจะโหลดมาใช้เองอัตโนมัติ
**ไม่ต้องแก้โค้ดเลย** — ถ้าไฟล์ไหนยังไม่มี เกมจะวาดพิกเซลอาร์ตแบบเดิม (โปรแกรมเมอร์อาร์ต) แทนไปก่อนแบบไร้รอยต่อ

ระบบนี้ทำงานเฉพาะตอนรันด้วย `npm run dev` / `npm run build` เท่านั้น (ต้องมีโฟลเดอร์ `public/` จริง) — **ใช้ไม่ได้** ตอนเล่นไฟล์เดียวใน artifact preview ของ Claude เพราะไม่มีระบบไฟล์ให้เสิร์ฟภาพ

---

## ขนาดพิกเซลแนะนำ

| ประเภท | ขนาดต่อเฟรม |
|---|---|
| ฮีโร่ผู้เล่น | 48×48 px |
| มอนสเตอร์ทั่วไป | 48×48 px (หรือ 64×64) |
| บอส | 96×96 px (หรือ 128×128 ถ้าต้องการให้ดูใหญ่กว่าฮีโร่ชัดเจน) |
| สัตว์เลี้ยง | 48×48 px |

**ขนาดจริงไม่ได้ถูกบังคับในโค้ด** — ระบบคำนวณขนาดเฟรมจาก `ความกว้างไฟล์จริง ÷ จำนวนคอลัมน์` เสมอ ตราบใดที่ทุกเฟรมในไฟล์เดียวกันมีขนาดเท่ากัน จะใช้ขนาดอะไรก็ได้ ตารางด้านบนเป็นแค่คำแนะนำให้ภาพดูสมส่วนกัน

## โครงสร้างแต่ละไฟล์ (แนวนอน 1 แถว = 1 ท่าทาง)

### ฮีโร่ (`hero_*.png`)
| แถว | ท่า | จำนวนเฟรม | รายละเอียด |
|---|---|---|---|
| 0 | Idle | 4 | ยืนหายใจเบาๆ / ขยับดาบเล็กน้อย |
| 1 | Attack | 4 | ง้างดาบ → ฟันโค้งกว้าง (เฟรมที่ 3 ควรเป็น smear frame ให้เห็นเป็นเส้นแสง) → ท่าจบ |
| 2 | Hurt | 2–4 | กระเด็นถอยหลังเล็กน้อย |

### มอนสเตอร์ / บอส (`mob_*.png`, `boss_*.png`)
| แถว | ท่า | จำนวนเฟรม | รายละเอียด |
|---|---|---|---|
| 0 | Idle | 4 | ขยับตัวขู่ช้าๆ |
| 1 | Hit | 2 | หดตัว หรือกะพริบสีขาวแวบหนึ่ง |
| 2 | Die | 4 | สลายตัว / ระเบิดกระจายเป็นชิ้นส่วนปริศนา |

### สัตว์เลี้ยง (`pet_*.png`)
เหมือนโครงมอนสเตอร์ (idle / hit / die) แต่ hit และ die ใช้ตอนสัตว์เลี้ยงตายไม่ได้ (สัตว์เลี้ยงไม่ตาย) — มีแค่แถว 0 (idle) ก็พอ แถวอื่นเผื่อไว้อนาคต

---

## ทุกเฟรมต้องมีคอลัมน์เท่ากันหมดในไฟล์เดียวกัน

ถ้าท่า Idle มี 4 เฟรม แต่ Hurt มีแค่ 2 เฟรม ให้ **เว้นที่ว่างโปร่งใส** ให้ครบ 4 คอลัมน์เท่ากับแถวอื่น (โค้ดสมมติว่าทุกแถวมีความกว้างเท่ากันหมด ถึงจะตัดเฟรมถูก)

---

## เมื่อไฟล์พร้อม

ไม่ต้องแก้ไฟล์ไหนในโปรเจกต์เลย แค่วางไฟล์ `.png` ที่ตั้งชื่อถูกต้องไว้ในโฟลเดอร์นี้ รันเกมใหม่ (`npm run dev`) ระบบจะตรวจเจอและใช้ภาพจริงแทนพิกเซลอาร์ตทันที ตัวไหนยังไม่มีไฟล์ก็จะใช้พิกเซลอาร์ตแบบเดิมต่อไปเรื่อยๆ — ผสมกันได้ ไม่ต้องทำให้ครบทุกตัวพร้อมกัน
